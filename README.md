# Cloud Maker

Учебный проект по курсу
«Современные облачные технологии», 2026.

## Описание

Cloud Maker — система для создания и управления
виртуальными машинами на Linux с использованием
QEMU/KVM и libvirt.

## Технологии

- Ubuntu 24.04 LTS
- QEMU/KVM
- libvirt
- Python 3.12
- FastAPI (планируется)
- cloud-init

## Реализованные пункты

Пункт 0 — запуск виртуальной машины через
командную строку с использованием QEMU/KVM.

## Системные требования

- Linux x86-64
- Поддержка аппаратной виртуализации
- Доступный KVM
- QEMU и libvirt

## Запуск и проверка

Инструкции будут добавлены вместе со скриптами
автоматического развёртывания.
